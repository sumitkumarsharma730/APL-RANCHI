hey # IPL Akinator

AI-powered IPL player guessing game built with:

* React + Vite frontend
* Node.js + Express backend
* Dynamic AI questioning engine
* Probability-based player prediction

## Features

* Adaptive questioning
* Session-based gameplay
* Confidence-driven guessing
* IPL player database
* Full-stack architecture

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
node src/server.js
```
